# 选题流程简化：去掉 02 价值初筛与 03 选题方案（daily_news v11）

> 2026-10-16 用户确认。本页是本次改动的接续锚点：每完成一步更新第 6 节。

## 1. 决定（用户 10-16 逐条确认）

1. 研究员的判断归 01：条目状态由 01 落定（推荐 → shortlisted + primary，备选 → shortlisted + alt，不推荐 → dropped + 理由码，待核 → pending_check）。
2. 01 主编闸维持只核格式（五项清单），内容意见写在通过意见里——读者从研究员换成 Van。
3. 保留阶段编号：02、03 空号，其余阶段名与存储路径不变。
4. 待核在 01 内闭环；交付时仍待核的 Van 不选，由主编之后用条目决定标继续研究或留下期。
5. 选题研究员完全下线（token 吊销、profile 停用、bot 移出群；roles 表记录保留供历史引用）。
6. Van 选题挪到 01：01 = 主编格式核对 → Van 选题（主编代录，末闸带 topic_approve + items），之后直接 04 / 05 / 06。
7. 01 一次交齐，取消「首批 + 补件追加批次」：01 补件会把 04 / 05 / 06 已开工任务全部标「补件待返工」（`supplement.go` 不按条目过滤）。Van 批准后加题一律走条目补批接口。
8. 「给 Van 的选题单」由工作台在 01 交付物里生成，主编不再另写选题方案。

## 2. 新流程

```
01 情报逐条（情报收集员 · 主编格式核对 → Van 选题，主编代录）
  ├→ 04 公众号写作（逐条）  ┐
  ├→ 05 配图与素材核（逐条）┴→ 07 内容整合稿（主编）
  └→ 06 版式与模板准备 ─────────→ 08 完整审核稿（Van 终审）
08 之后不变
```
