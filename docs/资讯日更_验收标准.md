# 资讯日更 · 验收标准

> 使用者：**主编**（审核每份交付物的尺子）。
> 用法：先查「通用合规项」，再逐条核对该阶段清单。**任一条不过 → 退回责任 Agent，写明改的方向和具体位置**（主编不代改），Agent 升版本重交。
> 流程：十阶段，公众号先行 → 小红书后接，全程一条线性链；每个生产段内部固定**文案 → 设计师**的先后。流程定义见《资讯日更 · 全流程》。
> 来源：所有条目提炼自各角色《作业手册》的规格要求与自检清单，以及《资讯日更 · 交付与流转规范》；本文件不新增要求。两边如有出入，以修订后最新一致版本为准。

---

## 0. 通用合规项（每份交付物都查）

- [ ] 文件名符合 `资讯日更_责任方_日期_任务ID_版本.zip`（任务ID=`r{run_id}`，同日多次任务互不覆盖），责任方与版本正确（单一产出=Agent 名；多方合成=阶段名「成品」；派工单=主编）
- [ ] OSS 路径为 `csw/资讯日更/{日期}/{任务ID}/{阶段序号-阶段}/`，阶段序号正确（01-采集 / 02-选题 / 03-公众号内容 / 04-公众号视觉 / 05-公众号成品 / 06-公众号发布 / 07-小红书文本 / 08-小红书视觉 / 09-小红书成品 / 10-小红书发布）
- [ ] 交付的是 OSS 返回的**完整 https 链接**（不能只写路径），zip 可下载、解压后以 `index.md` 为入口可读
- [ ] `index.md` 元信息头字段齐全：任务 / 类型 / 交付 Agent / 阶段 / 版本 / 时间 / 上游来源 / 状态 / 自检
- [ ] `阶段` 写**带序号的阶段名**；`上游来源` 写「来源方 · 完整 https 链接」，多个上游逐条列（**含 01-采集——其上游来源是主编任务启动派工单，不是「无」**）
- [ ] 附件按相对链接引用且全部可打开（如 `images/`、`source/`、`html/`、`xiaohongshu/`）
- [ ] 同名跨阶段产出（文案 03/07、设计师 04/08、发布员 06/10、成品 05/09）靠**阶段路径 + header 的 `阶段` 字段**区分，版本号在各阶段内各自从 v1 起算
- [ ] 返工件版本号已递增（v2/v3…），原版留底未删

## 共享前段（01–02）

### 01-采集（情报收集员）

**内容质量**
- [ ] 官方/账号情报为**完整内容**（完整文字 + 图片），来源如官方账号、品牌发布、固定关注账号
- [ ] 社区热门讨论为**热门内容**（热门帖 / 高赞讨论的文字 + 图片）
- [ ] 每条均标注来源平台（Instagram / 小红书 / 网页）、原文链接、发布时间，且原文链接可达
- [ ] 已去重；无与本号题材无关或无法溯源的内容
- [ ] 图片清晰、与资讯相关、数量充足（供选题研究员精选 15 张）；条数够当日所需

**规范合规**
- [ ] `index.md` 分「官方/账号情报 / 社区热门讨论」两栏
- [ ] 图片已下载进 `images/`（非外链裸 URL），正文相对链接可用
- [ ] 自检申报：Instagram 走 csw MCP；小红书 / 网页用 opencli（或 WebFetch），并按规定插入随机间隔

### 02-选题（选题研究员）

**内容质量**
- [ ] **恰好 5 则资讯**，且已排出当日呈现次序
- [ ] **恰好 15 张配图**已复制进 `images/`，每张标注归属哪一则资讯
- [ ] 每则资讯、每张图都能对应回资讯包具体条目与原文链接
- [ ] 所选资讯与配图契合公众号题材与调性
- [ ] **未越界写标题 / 摘要**（标题、摘要是文案的活）

**规范合规**
- [ ] `index.md` 含：5 则资讯（含排序）+ 配图清单（每张标注归属资讯）
- [ ] 15 张图在 `images/`，相对链接可用

## ① 公众号生产 · 母内容源（03–06，文案 → 设计师）

### 03-公众号内容（文案）

**内容质量**

*标题*
- [ ] 推文标题方案 2-3 个
- [ ] 标题符合 CAMPsomeWHERE 风格
- [ ] 标题不是产品型号堆砌
- [ ] 标题具有编辑角度
- [ ] 摘要 80-120 字
- [ ] 本期导读完整
- [ ] 导读格式统一（`01｜品牌｜一句话`）

*正文结构*
- [ ] 共 5 则资讯
- [ ] 顺序与选题成品一致
- [ ] 每则资讯标题格式：`品牌｜一句话标题`
- [ ] 每则资讯 300-500 字
- [ ] 每则资讯采用三段式结构（第一段 品牌背景+资讯总起；第二段 核心信息；第三段 编辑判断）

*编辑质量*
- [ ] 存在编辑判断
- [ ] 不只是复述品牌内容
- [ ] 说明差异点 / 使用场景 / 产品逻辑 / 趋势变化

*语言质量*
- [ ] 无公关稿语言（不得出现：重磅发布 / 震撼登场 / 诚意之作 / 引爆全网 / 重新定义）
- [ ] 保持编辑语气，不像百科、不像广告

*图片排版*
- [ ] 每则资讯 3 张图
- [ ] 图片1 位于标题下；图片2 位于第二段前；图片3 位于第三段前
- [ ] 图片与对应段落内容匹配

*封面推荐*
- [ ] 输出推荐资讯 / 推荐图片 / 推荐原因
- [ ] 关键信息出处可溯回情报原文链接

**规范合规**
- [ ] 正文为 md 格式；`index.md` 含 标题 / 摘要 / 导读 / 正文
- [ ] 配图在 `images/`，正文相对链接可用

### 04-公众号视觉（设计师）

**内容质量**
- [ ] 比例 **2.35:1**；尺寸 **1920 × 817 px**（如附小尺寸版，为 720 × 306 px）
- [ ] 主题契合 03 内容（标题 / 导读）
- [ ] 封面文字取自 03 标题（可精简），字号大、远看可读，在背景上可读性强
- [ ] 用了素材图时主体 / 构图 / 色彩 / 氛围未改、主要视觉区域未被遮挡
- [ ] 无日期、平台、作者名、水印等多余文字

*原图使用规范*
- [ ] 使用资讯原图
- [ ] 禁止重绘装备主体
- [ ] 禁止生成不存在的产品
- [ ] AI image-generate 仅用于版式与文字设计

*封面质量*
- [ ] 对应本期最重要资讯
- [ ] 缩略图状态可识别
- [ ] 标题两行以内
- [ ] 一眼看懂主题

**规范合规**
- [ ] 封面图在 `images/`；`index.md` 含设计意见（所用素材 / 提示词、思路、可调整项）
- [ ] 自检申报：封面由 `generate-images` skill 生成

### 05-公众号成品（主编合成前自检）

- [ ] 内容（03）、封面（04）两份均为**已过 Van 审**的最新版本
- [ ] `上游来源` 两条链接（内容 / 封面）齐全无误、可下载
- [ ] 责任方写「成品」，类型=成品；含主编意见与下一步安排；**已注明公众号文章作者名（按账号填写）**

### 06-公众号发布（发布员）

**内容质量**
- [ ] 正文 HTML 已生成、排版正常
- [ ] HTML 内图片已用 `mp-helper` 上传到公众号素材库，并已替换为素材库地址（无外链残留）
- [ ] 草稿箱字段齐全：文章封面图已设置；**标题=文案的标题（≤64 字符）**；摘要已填；**作者=按账号填写**（与派工单一致）
- [ ] 已保存进微信公众号**草稿箱**

**规范合规**
- [ ] 交付包含 `html/article.html`（图片替换后的公众号正文 HTML）；`index.md` 写明草稿箱位置与已填字段核对
- [ ] 发布员**先通知主编**（而非 Van）

## ② 小红书生产 · 二次拆解（07–10，一条 = 封面卡 + 内容卡 + 文本）

### 07-小红书文本（文案）

**内容质量**

*标题*
- [ ] 标题 18 字以内
- [ ] 单一传播点
- [ ] 点击导向
- [ ] 非公众号标题直接复制

*导语*
- [ ] 使用固定导语，格式：📢 户外内容平台 CAMPsomeWHERE ／ 👇为你播报过去24小时发布的户外潮流资讯

*正文*
- [ ] 保留全部资讯
- [ ] 每则资讯 200-300 字
- [ ] 重点资讯允许 300-400 字
- [ ] 不减少资讯数量

*排序*
- [ ] 优先传播力 / 优先爆款潜力
- [ ] 不强制照搬公众号顺序

*语言*
- [ ] 信息优先
- [ ] 不过度抒情、不写空话、不写总结式废话
- [ ] 保持小红书阅读节奏

*排版*
- [ ] 减少断行
- [ ] 连续阅读体验良好
- [ ] 不出现公众号式留白

**规范合规**
- [ ] `index.md` 含 笔记标题 + 笔记正文（无附件）

### 08-小红书视觉（设计师）

**内容质量**
- [ ] 比例 **3:4 竖版**；尺寸 **1242 × 1656 px**
- [ ] **封面卡 + 内容卡齐全**（数量按派工单）
- [ ] 内容取自 07 文本、与其一致
- [ ] 全套卡片风格统一、文字可读
- [ ] 无日期、平台、作者名、水印等多余文字

*封面卡*
- [ ] 使用资讯原图
- [ ] 主标题 / 副标题齐全

*内容卡*
- [ ] 标题 10-16 字
- [ ] 正文 200-300 字
- [ ] 保持留白、适配移动端阅读

*图片规范*
- [ ] 禁止重绘装备主体
- [ ] 禁止 AI 生成不存在产品
- [ ] 保留原资讯真实性

**规范合规**
- [ ] 卡片在 `xiaohongshu/`；`index.md` 含设计意见
- [ ] 自检申报：卡片由 `generate-images` skill 生成

### 09-小红书成品（主编合成前自检）

- [ ] 文本（07）、卡片（08）两份均为**已过 Van 审**的最新版本
- [ ] `上游来源` 两条链接（文本 / 视觉）齐全无误、可下载
- [ ] 责任方写「成品」，类型=成品；含主编意见与下一步安排；**已注明小红书是发布还是入草稿**

### 10-小红书发布（发布员）

**内容质量**
- [ ] 图文笔记由成品里的卡片 + 笔记文字组织而成，未自行改写内容
- [ ] 已用 `opencli xiaohongshu publish` 按派工单指示**发布或存入创作者中心草稿**
- [ ] 笔记 / 草稿位置可查

**规范合规**
- [ ] 交付包含 `xiaohongshu/笔记文案.md`（实发笔记标题 + 正文 + 所用卡片清单）；`index.md` 写明笔记 / 草稿位置与发布或入草稿结果
- [ ] 发布员**先通知主编**（而非 Van）
