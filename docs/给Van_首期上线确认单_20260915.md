## 五、9/16 首期复盘与今天的改动

主编就此写了《选题交付改进方案》，属于流程的部分今天已经改进引擎并上线：

| 改动 | 对你意味着什么 |
|---|---|
| 01 情报新增「主编首批校准」闸 | 首批线索（4–8 条，含原文、原始时间、预览图）一到齐，主编先定方向：哪些继续、哪些停。弱题在这一步被挡下，不会做完整了才送到你面前 |
| 02 改为「价值 + 资格」两道轻检查 | 先判值不值得看、是不是新披露和有没有重复，都成立才深挖；关键事实没核实的标「待核」，不算进成熟数量 |
| 03 选题方案按五栏交付 | 线索、待核、成熟主选、成熟备选、你已批准，各多少条一目了然；不再把还在研究的算成备选 |
| 补证有停止条件 | 追加研究前先回答「查清这个问题能不能改变采用决定」；同一个问题一轮解决不了就停这条，不拖住其他候选 |
| 排重资料开工即在手 | 01/02/03 的任务里自动带近 30 天已发（含群发）和最近被否决的条目及理由，不用你再补链接 |
| 每期出耗时报告 | 实际作业、等主编、等你、返工轮次分开记，用结果验证改进，不合并后归咎于人审 |

你的两处拍板没有变化：07:15 选题、09:00 完整推文。9/17 05:30 这一期就按新流程跑。
